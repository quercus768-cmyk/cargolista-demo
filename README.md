# CargoLista — How It Works

Локальная демонстрация компьютерной версии страницы. Откройте `index.html` в браузере или запустите в этой папке `python -m http.server 8000` и откройте http://localhost:8000/.

Навигация и кнопки показаны только визуально: другие страницы и функции не реализованы. Мобильная версия не разрабатывалась. Логотип и иконки восстановлены по изображению; исходный шрифт не предоставлен.
