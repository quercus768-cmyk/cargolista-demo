# CargoLista — How It Works

Локальная демонстрация компьютерной версии страницы. Откройте `index.html` в браузере или запустите в этой папке `python -m http.server 8000` и откройте http://localhost:8000/.

Навигация и кнопки показаны только визуально: другие страницы и функции не реализованы. На узких экранах меню раскрывается, карточки перестраиваются. Мобильный макет создан самостоятельно: исходный пример есть только для компьютера. Логотип и иконки восстановлены по изображению; исходный шрифт не предоставлен.
